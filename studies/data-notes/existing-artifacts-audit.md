# Existing-artifact audit

Audit date: 2026-09-28 (study cutoff), performed against the frozen repository
heads in `experiments/results/repository-snapshot.json`.

## Reused

- `experiments/data/vllm-log.txt`: 22,106 parseable first-parent records,
  matching the frozen clone's first-parent count.
- `experiments/data/sglang-log.txt`: 19,040 parseable first-parent records,
  matching the frozen clone's first-parent count.
- The blobless Git object stores under `experiments/data/repos/` are retained
  as provenance for commit SHAs and metadata. Their working trees are empty, so
  scripts use the cached name-only logs and `git show` for targeted historical
  content rather than assuming checked-out files exist.
- `experiments/scripts/effort_breakdown.py` is retained as the pilot's
  provenance, but not as the final measurement instrument.

## Rejected as final evidence

- `experiments/results/{vllm,sglang}-commits.csv`,
  `{vllm,sglang}-quarterly.csv`, and `*-effort.png` were generated by the pilot
  classifier. They omit orthogonal claim fields, contributor concentration,
  kernel-touch reasons, uncertainty, partial-quarter markings, and validation.
  They may be overwritten only by the reproducible validated pipeline.
- `experiments/data/vllm-commits.csv` and
  `experiments/data/vllm-quarterly.csv` duplicate pilot derived outputs and are
  not treated as raw data.
- No prior PR-rule audit, API cache, validation labels, lifecycle dataset,
  methods document, consistency check, or report was present.

## Repairs required

The final classifier must separate engineering purpose from kernel
implementation touch, distinguish implementation from tests or benchmarks,
record hardware/optimization/correctness claims independently, and preserve the
classification signal. Validation must precede any public percentage. GitHub
collection must be cached and checkpointed in batches of at most 250 records.
